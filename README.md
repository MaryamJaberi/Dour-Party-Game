# دور — Dour Party Game

بازی مهمانی پاس‌دادن گوشی برای یادگیری زبان. هم‌تیمی‌ها روبه‌روی هم می‌نشینند، کارت عبارت می‌آید، یار باید همان را بگوید.

این نسخهٔ کامل رابط کاربری تیره، چندزبانه، با بانک عبارت A1 / A2 / B1 و تلفظ آنلاین است.

## بازی آنلاین

بعد از فعال‌شدن GitHub Pages:

**https://maryamjaberi.github.io/Dour-Party-Game/**

## اجرای محلی

```bash
npm install
npm run dev
```

سپس مرورگر را روی آدرس Vite (معمولاً `http://localhost:5173`) باز کنید.

## ساخت

```bash
npm run build
npm run preview
```

## امکانات

- زبان برنامه جدا از زبان مادری و زبان‌های هدف کارت‌ها
- رابط کامل به همهٔ زبان‌های بانک عبارت
- لیست‌های جمع‌شونده، هدر و فوتر ثابت
- تلفظ (Web Speech + گوگل در حالت آنلاین)
- صداهای بازی، میز نشستن، نوبت پاس‌دادن گوشی

## داده

عبارت‌ها در [`src/data/phrases.json`](src/data/phrases.json) هستند (سطح‌های CEFR A1، A2، B1).
